🏦 Bank Customer Churn Prediction using Power BI
Recommended Structure and Order

1. Project Title / Headline
Customer Churn Prediction: Bank Customer Churn Analysis Dashboard using Power BI
A dynamic and interactive Power BI dashboard developed to analyze customer churn patterns in the banking sector. The dashboard provides insights into customer demographics, account balances, credit scores, product usage, geography, and churn behavior, helping businesses identify customer retention trends and support data-driven decision-making.

2. Short Description / Purpose
The Bank Customer Churn Analysis Dashboard is an interactive Power BI report that transforms raw customer data into meaningful business insights. It enables users to analyze customer churn based on age, gender, geography, credit score, account balance, products, and customer activity. Through interactive visualizations, the dashboard helps identify churn patterns and supports strategies to improve customer retention.

3. Tech Stack
The dashboard was built using the following tools and technologies:
📊 Power BI Desktop – Dashboard design and data visualization.
🔄 Power Query – Data cleaning, transformation, and preprocessing.
📈 DAX (Data Analysis Expressions) – Calculated measures and KPIs.
🔗 Data Modeling – Relationship management between tables.
📄 Excel Dataset (.xlsx) – Bank customer churn dataset used for analysis.

4. Data Source
Source: Bank Customer Churn Dataset (Excel)
The dataset contains customer information, including age, credit score, account balance, estimated salary, geography, gender, tenure, number of products, active status, and churn status. The data was cleaned and transformed using Power Query before creating the dashboard.

5. Features / Highlights
Business Problem
Banks often lose customers due to various factors such as low engagement, product usage, or customer demographics. Identifying customers who are likely to leave is challenging when analyzing raw data. This dashboard transforms customer information into interactive visual insights that help understand churn patterns and support customer retention strategies.

6. Goal of the Dashboard
Analyze customer churn by gender and geography.
Monitor customer balance, credit score, and salary.
Compare churn across different product categories.
Track customer activity and tenure.
Support data-driven customer retention decisions.
